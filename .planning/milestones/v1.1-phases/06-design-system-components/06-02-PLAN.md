**Avatar.tsx** (COMP-01):
- Props: `userId: string`, `name: string`, `size?: AvatarSize` (default 'md')
- AvatarSize type: 'xs' | 'sm' | 'md' | 'lg' | 'xl' | '2xl'
- Size map: xs=24, sm=32, md=40, lg=48, xl=56, 2xl=72
- Font size map: xs=10, sm=12, md=14, lg=18, xl=22, 2xl=28
- Initials: first letter of each word in name, max 2 characters, uppercase
- Gradient: Use `expo-linear-gradient` LinearGradient with deterministic color pair from userId hash
- Gradient pairs (8 total): emerald, blue, violet, pink, amber, red, cyan, lime (exact hex values from 06-RESEARCH.md Pattern 4)
- Hash function: simple charCodeAt loop with modulo (from research)
- Colored shadow: shadowColor matches the start gradient color, shadowOffset {0, 2}, shadowOpacity 0.3, shadowRadius 4, elevation 3
- White text for initials, fontWeight '600'
- Export both the component and `getGradientForUser` function (other components may need the color)

**Card.tsx** (COMP-02):
- Props: `children: React.ReactNode`, `className?: string` (for additional NativeWind classes)
- Default styling via NativeWind: `bg-white rounded-card border border-neutral-border shadow p-4`
- Uses `rounded-card` (12px from tailwind.config.js token)
- Merge className prop with defaults using template literal
- Shadow on iOS via NativeWind class, elevation: 2 on Android via inline style (per research pitfall #1)
- Must have explicit `bg-white` for shadow to render (per research anti-pattern)

**Badge.tsx** (COMP-03):
- Props: `label: string`, `variant?: BadgeVariant` (default 'neutral')
- BadgeVariant type: 'brand' | 'success' | 'warning' | 'error' | 'info' | 'neutral'
- Variant styles map — soft colored background with darker text of same hue:
  - brand: bg-brand-light (#D1FAE5) + text-brand-dark (#059669)
  - success: bg-green-100 + text-green-700 (use hardcoded in className)
  - warning: bg-amber-100 + text-amber-700
  - error: bg-red-100 + text-red-700
  - info: bg-blue-100 + text-blue-700
  - neutral: bg-neutral-surface + text-neutral-secondary
- Shape: pill (rounded-full), horizontal padding px-2.5, vertical py-0.5
- Text: text-badge preset (11px, font-weight 500)
- NOTE: The bg-green-100, bg-amber-100, etc. are Tailwind defaults (not our custom tokens). They're used here because badge backgrounds need lighter tints than our semantic colors. This is intentional.

**Button.tsx** (COMP-04):
- Props: `title: string`, `onPress: () => void`, `variant?: 'primary' | 'outline'` (default 'primary'), `disabled?: boolean`, `loading?: boolean`, `className?: string`
- Primary variant: `bg-brand rounded-full` (pill shape per user decision), white text, font-weight 600
- Outline variant: `border-2 border-brand rounded-full` + `text-brand`, transparent background
- Disabled state: opacity-50, press handler disabled
- Loading state: replace text with ActivityIndicator (white for primary, brand color for outline)
- Use Pressable from react-native (not TouchableOpacity)
- Size: py-3 px-6, text-body (15px)
- Press state: opacity feedback via Pressable's `style` function with pressed state

**IconContainer.tsx** (COMP-05):
- Props: `name: string` (Ionicons name), `variant?: IconContainerVariant` (default 'brand'), `size?: number` (icon size, default 20)
- IconContainerVariant type: 'brand' | 'success' | 'warning' | 'error' | 'info' | 'neutral'
- Container: 40x40px, rounded-xl (16px radius per rounded square spec), centered content
- Variant color mapping (background + icon color):
  - brand: bg-brand-light (#D1FAE5) + icon brand-dark (#059669)
  - success: bg-green-100 + icon green-600
  - warning: bg-amber-100 + icon amber-600
  - error: bg-red-100 + icon red-600
  - info: bg-blue-100 + icon blue-600
  - neutral: bg-neutral-surface + icon neutral-secondary
- Use Ionicons from @expo/vector-icons
- Import colors from @/lib/theme/colors for icon color prop (can't use Tailwind for icon color)

**Toggle.tsx** (COMP-06):
- Props: `value: boolean`, `onChange: (value: boolean) => void`, `locked?: boolean` (default false)
- Track: 48px wide, 28px tall, rounded-full (pill)
- Thumb: 24px circle, white, subtle shadow
- Animation: react-native-reanimated withSpring for both track color and thumb position
  - Track color: interpolateColor from neutral.border (#E2E8F0) when off to brand (#10B981) when on
  - Thumb translateX: 0 when off, 20px when on (48 - 24 - 4 padding = 20)
  - Spring config: damping 15, stiffness 300
- Locked state: opacity 0.5, press handler returns early (no toggle)
- Use Pressable for tap handling
- Import Animated, useSharedValue, useAnimatedStyle, withSpring, interpolateColor from react-native-reanimated
- Use useEffect to sync animation when `value` prop changes externally
