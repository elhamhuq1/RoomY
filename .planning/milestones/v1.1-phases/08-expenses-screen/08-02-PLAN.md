  <action>
Create a new screen at `app/(app)/expenses/member-history.tsx` that shows all expenses and settlements between the current user and a specific member.

**Route params:**
- `userId` (string) -- the other member's user ID, passed via query param from the balance section.

**Data fetching:**
- Fetch the other member's profile to get their display name (for the header title).
- Fetch expenses where `household_id` matches AND either:
  - `paid_by === userId` (they paid, you have a split), or
  - `paid_by === currentUserId` (you paid, they have a split)
  - Then filter to only include expenses where BOTH users appear in the splits (fetch expense_splits for these expense IDs, keep only those where both user IDs appear).
- Fetch settlements where (`paid_by === userId AND paid_to === currentUserId`) OR (`paid_by === currentUserId AND paid_to === userId`).
- Use the same `getDateGroup()` function from Plan 01 to bucket into TODAY / YESTERDAY / EARLIER groups.
- Sort newest first within each group.

**Simpler alternative approach (recommended for accuracy):**
  1. Fetch all expense_splits where `user_id = otherUserId` to get expense IDs involving them.
  2. Fetch those expenses by ID.
  3. Filter to expenses in the current household.
  4. Fetch settlements between the two users in this household.
  5. Merge, sort, and group.

**Screen layout:**
- Stack header with the member's name as title. Use `<Stack.Screen options={{ title: memberName }} />` pattern from expo-router.
- ScrollView with pull-to-refresh (same RefreshControl pattern).
- Reuse `ExpenseRow` and `SettlementRow` components from `@/components/expenses` for consistent visual styling.
- Date group headers use same overline styling: `<Text className="text-overline text-neutral-secondary uppercase mb-2">{group.label}</Text>`.
- Wrap each group's items in a `Card` from `@/components/ui`.
- Support inline expand for expense rows (same expandedId + splitsCache pattern as main screen).
- If no history between the two users, show a simple empty state: "No expenses with {name} yet".

**Loading state:** Centered ActivityIndicator with brand color.

**Padding:** contentContainerStyle={{ paddingHorizontal: 20, paddingTop: 16, paddingBottom: 32 }}.

**Do NOT:**
- Add search or filtering (deferred).
- Add pagination (per-member history is typically small; can add later if needed).
- Modify any existing files -- this is a new file only.
