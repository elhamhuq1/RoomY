## Tests

### 1. Chores Tab Empty State
expected: Navigate to the Chores tab. You should see a friendly empty state with "No chores yet!" message and a grid of 7 suggested chores with icons (Dishes, Take out trash, Vacuum, Clean bathroom, Mop floors, Wipe counters, Laundry). A "+" FAB button should be visible in the bottom-right corner.
result: pass

### 2. Create Chore from Suggestion
expected: Tap one of the suggested chores (e.g., "Dishes"). The Add Chore screen opens with the name pre-filled. You should see frequency picker chips (Daily, Weekly, Monthly, Custom) and a list of household members with checkboxes (all checked by default).
result: pass

### 3. Create a Chore
expected: On the Add Chore screen, select a frequency (e.g., "Weekly"), leave all members checked, and tap "Create Chore". You should be taken back to the chore list, and the chore now appears under "My Chores" section with the frequency badge and a due date.
result: pass

### 4. Summary Header Stats
expected: With at least one chore created, the top of the Chores screen shows a summary header with three stat cards: pending count (number of chores assigned to you), overdue count, and streak count.
result: pass

### 5. Create a Second Chore via FAB
expected: Tap the "+" FAB in the bottom-right corner. The Add Chore screen opens with an empty name field. Type a custom chore name, pick a frequency, and create it. It appears in the chore list.
result: pass

### 6. Complete a Chore
expected: On a chore in your list, tap the checkmark (complete) button. A confirmation dialog appears: "Mark Complete?" with Cancel and Complete options. Tap "Complete". The chore updates — it should rotate to the next person and show a new due date.
result: pass

### 7. Chore List Grouping
expected: After completing a chore (which rotated it to another member), the chore list shows two sections: "My Chores" (chores assigned to you) at the top, and "Household Chores" (assigned to others) below.
result: pass

### 8. Claim Another's Chore
expected: On a chore in the "Household Chores" section (assigned to someone else), you should see an "I'll do it" button (hand-raise icon). Tap it. The chore moves to "My Chores" section, now assigned to you.
result: pass

### 9. Dispute a Completion
expected: On a chore that was recently completed by someone else (has a last_completed_at), tap the flag icon. A confirmation dialog appears warning about the 24-hour auto-revert. Confirm the dispute. A "Disputed" badge appears on that chore row.
result: pass

### 10. Request a Swap
expected: On a chore assigned to you, tap the swap icon (swap-horizontal). A modal appears showing other household members. Select a member to request a swap with. You should see a success confirmation, and a pending swap count banner appears.
result: pass

### 11. Swap Request Screen
expected: Navigate to the swap requests screen (tap the swap icon in the chores tab header). You should see your outgoing request with "Pending" status. If you have incoming requests from others, Accept and Decline buttons appear.
result: pass

### 12. Contribution Dashboard
expected: Tap the dashboard/chart icon in the chores tab header. The dashboard shows a "This Week" / "This Month" toggle, household totals (completed, active chores, avg per member), and per-member cards with avatar, completion count, streak (flame icon), and a relative progress bar.
result: pass
