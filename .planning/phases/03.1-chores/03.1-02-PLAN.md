**Update `app/(app)/(tabs)/chores.tsx`** to add dispute and swap capabilities:

**Dispute button on each chore row:**
- Add a "flag" icon button (Ionicons `flag-outline`) on chore rows that have recent completions (last_completed_at is not null)
- On tap: `Alert.alert('Dispute Completion?', 'Flag the last completion as not actually done. If unresolved within 24 hours, it will be automatically reverted.', [{text: 'Cancel', style: 'cancel'}, {text: 'Dispute', style: 'destructive', onPress: () => handleDispute(choreId)}])`
- handleDispute: fetch the most recent non-reverted completion for this chore from chore_completions (ORDER BY completed_at DESC LIMIT 1), then call `supabase.rpc('dispute_completion', {p_completion_id: completion.id, p_disputed_by: user.id})`, refresh list
- Only show the dispute button if the last completion was NOT by the current user (can't dispute your own completion)

**Dispute badge on chore rows:**
- Query chore_completions for each chore to check if any recent completion is_disputed = true AND is_reverted = false
- Show an orange/amber badge "Disputed" next to the chore name if so
- If the disputed completion was completed_by the current user, show "Your completion was disputed" text in the row

**Swap request button:**
- On each chore row assigned to the current user, add a "swap" icon button (Ionicons `swap-horizontal-outline`)
- On tap: show a Modal with a list of other household members. User picks who to request a swap with.
- On member selection: insert into chore_swap_requests (chore_id, requested_by: user.id, requested_to: selectedMember.id), show success toast/alert, close modal

**Swap request badge in header:**
- Count pending swap requests where requested_to === user.id
- Show a badge count on the swap/dashboard icon in the header
- Tapping the badge navigates to `/(app)/chores/swap-request`

**Client-side dispute revert check (fallback if pg_cron unavailable):**
- On screen load (in the useFocusEffect), also query for disputed completions where disputed_at < 24 hours ago and is_reverted = false
- If found, call a simple update to revert them (or an RPC). This ensures reverts happen even if pg_cron isn't running.

**Create `app/(app)/chores/swap-request.tsx`** -- Swap Request screen:
- Header: "Swap Requests"
- Two sections: "Incoming" (requests where requested_to === user.id, status === 'pending') and "Outgoing" (requests where requested_by === user.id)
- Each incoming request row: chore name, requester name (from profiles), "Accept" and "Decline" buttons
- Accept: call `supabase.rpc('resolve_swap_request', {p_request_id: id, p_status: 'accepted'})`, refresh
- Decline: call `supabase.rpc('resolve_swap_request', {p_request_id: id, p_status: 'declined'})`, refresh
- Each outgoing request row: chore name, target person name, status badge (pending/accepted/declined)
- Empty state: "No swap requests" message
- Use two-query pattern for member profiles
- Use ScrollView with inline style={{ flex: 1 }}

**Create `app/(app)/chores/dashboard.tsx`** -- Contribution Dashboard screen:

**Header:** "Chore Dashboard" with a segmented control / toggle for time period: "This Week" | "This Month"
- "This Week" = Monday 00:00 to Sunday 23:59 of current week
- "This Month" = 1st 00:00 to last day 23:59 of current month
- Default to "This Week" on load

**Stats per member:**
- Fetch chore_completions for the household within the selected date range, filtered by is_reverted = false
- Join/correlate with profiles to get display names (two-query pattern: fetch completions, extract unique completed_by UUIDs, fetch profiles)
- For each member, compute:
  1. **Completion count**: number of non-reverted completions in the period
  2. **Current streak**: consecutive non-reverted completions (global, not per-chore), counting backwards from most recent. A streak breaks at the first reverted completion or a gap (completion by someone else in between for the same chore doesn't break global streak -- only reverts break it).

**Layout per member:**
- Member card showing: avatar placeholder (first letter of display name in a colored circle), display name, completion count as a large number, streak as "X streak" with a flame icon (Ionicons `flame-outline`)
- Below the count: a simple horizontal bar showing relative contribution. The member with the most completions gets a full-width bar, others are proportional. Use primary-400 color for the bar, gray-200 for the track.
- Cards are in a vertical list (ScrollView with inline style={{ flex: 1 }})

**Household totals row at top:**
- Total completions this period, total active chores, average completions per member

**Edge cases:**
- No completions in period: show "No chores completed this [week/month]" message
- Only one member: still show their stats (no comparison needed)
- Reverted completions are excluded from all counts

**Styling:**
- Use NativeWind classes throughout
- Primary-100 card backgrounds, white inner cards for member stats
- Consistent with app's visual language (amber/gold primary, gray text hierarchy)
