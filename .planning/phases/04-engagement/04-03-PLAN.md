**Create `lib/notifications.ts`** with:

1. `registerForPushNotifications(userId: string): Promise<string | null>`
   - Guard with `Device.isDevice` check -- return null and log message if not physical device (push won't work in Expo Go or simulators)
   - Check existing permission status with `Notifications.getPermissionsAsync()`
   - If not granted, request with `Notifications.requestPermissionsAsync()`
   - If still not granted, return null
   - Get Expo push token: `Notifications.getExpoPushTokenAsync({ projectId })` where projectId comes from `Constants?.expoConfig?.extra?.eas?.projectId ?? Constants?.easConfig?.projectId`
   - Store token in profiles table: `supabase.from('profiles').update({ expo_push_token: token }).eq('id', userId)`
   - Return the token string
   - Import supabase from '@/lib/supabase'

2. `setupNotificationChannels(): Promise<void>`
   - Guard with `Platform.OS !== 'android'` -- return early on iOS
   - Create 'expenses' channel: name "Expenses", importance HIGH, vibration pattern [0, 250, 250, 250], lightColor '#3b82f6'
   - Create 'chores' channel: name "Chore Reminders", importance DEFAULT, vibration pattern [0, 250], lightColor '#22c55e'

**Update `app/_layout.tsx`**:

1. Add imports at top of file:
   - `import * as Notifications from 'expo-notifications'`
   - `import { registerForPushNotifications, setupNotificationChannels } from '@/lib/notifications'`
   - `import { useRouter } from 'expo-router'`
   - `import { useEffect, useRef } from 'react'`

2. Add notification handler OUTSIDE any component (module-level, before RootNavigator):
```typescript
Notifications.setNotificationHandler({
  handleNotification: async () => ({
    shouldShowAlert: true,
    shouldPlaySound: true,
    shouldSetBadge: false,
  }),
});
```

3. Create a `useNotificationSetup()` hook used inside RootNavigator (or a new wrapper component):
   - Only run when user is authenticated (session exists)
   - In useEffect (with session?.user?.id dependency):
     - Call `setupNotificationChannels()`
     - Call `registerForPushNotifications(session.user.id)`
   - Set up notification response listener (for deep-linking on tap):
     - `Notifications.addNotificationResponseReceivedListener(response => { ... })`
     - Extract `data` from `response.notification.request.content.data`
     - If `data.type === 'expense' && data.expenseId`: `router.push('/(app)/expenses/' + data.expenseId)`
     - If `data.type === 'chore'`: `router.push('/(app)/(tabs)/chores')`
   - Clean up listener on unmount

IMPORTANT: Keep the existing RootLayout structure intact (GestureHandlerRootView > AuthProvider > RootNavigator). Add the notification setup hook call inside RootNavigator after the `useSession()` call, guarded by `isAuthenticated`.

Do NOT wrap in try/catch that silently swallows errors -- log errors to console so they're visible during development. But DO handle the case where push registration fails gracefully (user denied permission, not a physical device, etc.) -- the app should still work without push.
