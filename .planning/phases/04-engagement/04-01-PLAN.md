Create `lib/calendar-utils.ts` with two exported functions:

1. `buildMarkedDates(expenses: Expense[], chores: Chore[], monthDate: Date): MarkedDates`
   - Takes arrays of expenses and chores plus the currently visible month
   - For each expense, add a blue dot on its `created_at` date (key: 'expense', color: '#3b82f6')
   - For each chore, project future due dates within the month range using `projectChoreDates()`:
     - Start from chore.next_due_at, walk forward using frequency (daily -> addDays(1), weekly -> addWeeks(1), monthly -> addMonths(1), custom -> addDays(custom_interval_days ?? 7))
     - Also walk backward from next_due_at to find dates within the visible month that are before next_due_at
     - Add green dot (key: 'chore', color: '#22c55e') for each projected date
   - Return MarkedDates object compatible with react-native-calendars multi-dot marking
   - Only process dates within the visible month (startOfMonth to endOfMonth) to avoid performance issues

2. `getEventsForDate(date: string, expenses: Expense[], chores: Chore[]): CalendarEvent[]`
   - Returns array of CalendarEvent objects for a given date string (yyyy-MM-dd)
   - Each CalendarEvent has: id, type ('expense' | 'chore'), title, detail, icon (Ionicons name), color, deepLink
   - For expenses: title = description, detail = "$X.XX", icon = "wallet", color = "#3b82f6", deepLink = `/(app)/expenses/${id}`
   - For chores: title = chore name, detail = assignee display name or "Unassigned", icon = "checkbox", color = "#22c55e", deepLink = `/(app)/chores` (chores don't have individual detail screens)
   - Match expenses by comparing format(created_at, 'yyyy-MM-dd') === date
   - Match chores by checking if date falls on a projected due date using the same projection logic

Export CalendarEvent type from the file.

Add to `lib/types/database.ts`: No new types needed (Expense and Chore interfaces already exist). But verify the Chore interface has `frequency`, `custom_interval_days`, and `next_due_at` fields (it does per current file).

Use date-fns functions: format, startOfMonth, endOfMonth, addDays, addWeeks, addMonths, isBefore, isAfter, parseISO.
