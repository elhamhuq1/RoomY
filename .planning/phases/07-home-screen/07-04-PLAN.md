Four targeted fixes:

**1. Fix myNetAmount computation in app/(app)/(tabs)/index.tsx (lines 170-173)**

This is a MAJOR bug: the balance card always shows "All settled up" regardless of actual balances. Root cause: `myNetAmount` uses `balances.find(b => b.user_id === user?.id)` but the `get_household_balances()` RPC only returns rows for OTHER users (WHERE other_user != auth.uid()). The current user's ID is never in the result set, so myBalance is always undefined and myNetAmount is always 0.

Replace the current myNetAmount useMemo:
```
const myNetAmount = useMemo(() => {
  const myBalance = balances.find((b) => b.user_id === user?.id);
  return Number(myBalance?.net_amount ?? 0);
}, [balances, user?.id]);
```

With a `.reduce()` that sums all balance rows:
```
const myNetAmount = useMemo(() => {
  return balances.reduce((sum, b) => sum + Number(b.net_amount), 0);
}, [balances]);
```

Rationale: Each row returned by get_household_balances() represents the pairwise net between the current user and one other household member. Positive net_amount = that member owes the current user; negative = current user owes them. Summing all rows gives the current user's overall net position. The `user?.id` dependency is no longer needed since we sum all rows (the RPC already scopes to the current user via auth.uid()).
