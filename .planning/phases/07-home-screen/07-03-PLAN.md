Completely rewrite `app/(app)/(tabs)/index.tsx` to compose all 6 section components with centralized data fetching.

**Data fetching (centralized in the parent):**
- Use `useSession()` to get `{ user, household, profile, householdSettings }`
- Use `useFocusEffect` to refresh data when screen gains focus
- Fetch ALL data in parallel using `Promise.all`:
  1. Members: Two-query pattern from existing code (household_members + profiles, combine client-side)
  2. Balances: `supabase.rpc('get_household_balances', { p_household_id: household.id })`
  3. Expenses: `supabase.from('expenses').select('*').eq('household_id', household.id)` for current month range
  4. Chores: `supabase.from('chores').select('*').eq('household_id', household.id).eq('is_active', true)`
  5. Overdue chores: Filter from chores where `next_due_at < now` and (optionally `current_assignee === user.id` for user's own overdue)
  6. Pending disputes: `supabase.from('chore_completions').select('*, chores!inner(name)').eq('is_disputed', true).eq('is_reverted', false)`
- Maintain `refreshing` state for pull-to-refresh via `RefreshControl`
- Maintain `loading` state; show `ActivityIndicator` centered on first load
- Maintain `selectedDate` state initialized to today (`format(new Date(), 'yyyy-MM-dd')`)

**Screen composition (single ScrollView, per user decision):**

```
</ScrollView>
```

**Section spacing:** Each section component has internal horizontal padding (px-5). Between sections, use `mt-4` on each section's outer View for 16px vertical gaps (spacious density per user decision).

- `firstName`: extract from `profile?.display_name?.split(' ')[0] ?? ''`
- `myNetAmount`: find current user in balances array: `balances.find(b => b.user_id === user?.id)?.net_amount ?? 0`, cast to Number

- `onCardPress` navigates to `/(app)/(tabs)/expenses`
- Build `unsettledBalances` array: from balances where amount !== 0, cross-ref with member profiles for display names. Show members who owe the current user (positive amounts from current user's perspective) or whom the current user owes (negative amounts).
- Build `overdueChores` array: chores where `next_due_at < new Date().toISOString()`
- Build `choresDueToday` array: chores where next_due_at is today (use `isSameDay` from date-fns)
- Build `weekChores` array for WeeklyTimeline: chores with projected due dates in current week, with completion status. Map to the expected prop shape (id, name, assigneeId, assigneeName, dueDate, isCompleted).
- `selectedDate` filtering: When user taps a calendar day, pass that date to WeeklyTimeline to filter. If selectedDate is today (default), pass `null` to show all week items.
