- Props: `icon: string` (Ionicons name), `onPress: () => void`
- Shape: 52x52px, borderRadius 16px (rounded square, NOT circular)

  - iOS: `shadowColor: colors.brand.DEFAULT`, `shadowOffset: { width: 0, height: 4 }`, `shadowOpacity: 0.35`, `shadowRadius: 8`
  - Android: `elevation: 6`
- Scale bounce animation using react-native-reanimated:
  - `onPressIn`: `scale.value = withSpring(0.92, { damping: 15, stiffness: 300 })`
  - `onPressOut`: `scale.value = withSpring(1, { damping: 12, stiffness: 200 })`
  - Use `useSharedValue(1)` for scale
  - Use `useAnimatedStyle` to apply transform: [{ scale: scale.value }]
  - Use `Animated.createAnimatedComponent(Pressable)` for AnimatedPressable
- Center icon within the square using `alignItems: 'center', justifyContent: 'center'`

**Integrate FAB into tab layout:**
Import FAB from `@/components/ui/FAB` (or `@/components/ui` barrel).

Add FAB rendering inside the Tabs component, after all Tabs.Screen elements but still within the `<Tabs>` wrapper. The FAB should be conditionally rendered with a contextual icon based on the active tab. This requires knowing the current route.

Use `usePathname` from expo-router to determine which tab is active and set the icon/action:
```tsx
import { usePathname } from 'expo-router';
// ...
const pathname = usePathname();

// Determine FAB icon and action based on active tab
const getFABConfig = () => {
  if (pathname.includes('/expenses')) return { icon: 'add', onPress: () => router.push('/(app)/expenses/add') };
  if (pathname.includes('/groceries')) return { icon: 'add', onPress: () => { /* handled by groceries screen inline */ } };
  if (pathname.includes('/chores')) return { icon: 'add', onPress: () => router.push('/(app)/chores/create') };
  return null; // No FAB on home tab
};

const fabConfig = getFABConfig();
```

Render the FAB as a sibling to `<Tabs>` by wrapping everything in a `<View style={{ flex: 1 }}>`:
```tsx
return (
  <View style={{ flex: 1 }}>
    <Tabs screenOptions={...}>
      {/* ... tabs ... */}
    </Tabs>
    {fabConfig && <FAB icon={fabConfig.icon} onPress={fabConfig.onPress} />}
  </View>
);
```

NOTE: The groceries tab currently has inline add functionality (text input at bottom). The FAB for groceries may navigate to a different action or be omitted — use your judgment. At minimum, expenses (add expense) and chores (create chore) should have FAB actions. Home tab has no FAB.
