Test on your iPhone via Expo Go. Run through these 9 scenarios:

**Scenario 1: Add First Expense**
1. Navigate to Expenses tab — should show empty state ("No expenses yet")
2. Tap the (+) FAB button — Add Expense form opens
3. Enter description "Electric bill", amount "120.00"
4. Verify payer defaults to you
5. Verify all household members are pre-selected with equal split amounts shown
6. Deselect one member — verify share amounts recalculate

**Scenario 3: Add Second Expense (Different Payer)**

**Scenario 4: Expense Detail + Edit**
14. Tap an expense in history — detail screen opens
15. Verify all split members shown with individual amounts
16. Tap Edit — modify the description or amount
17. Save — verify history and balances update

**Scenario 5: Delete Expense**
18. Open an expense detail — tap Delete
19. Confirm deletion — verify expense removed from history
20. Verify balances recalculate after deletion

**Scenario 6: Settle Up**

29. Settle all outstanding balances — verify "All settled up!" message appears

**Scenario 9: Recent Descriptions**
