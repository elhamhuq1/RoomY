**Create `app/(app)/expenses/settle.tsx`:**

Receives route params: `userId` (the other person), `amount` (suggested settlement amount), `direction` (owed_to_you | you_owe).

**Screen layout:**
1. **Header area:** Shows the other person's avatar initials + display name (fetch profile by userId).
2. **Direction label:** "You owe [Name]" or "[Name] owes you" depending on direction.
3. **Amount field:** Pre-filled with the net balance amount. Editable TextInput with keyboardType="decimal-pad" for partial settlements. Prefixed with "$". Validate > 0 and <= original amount (warn if exceeding but allow it — user might be pre-paying).
4. **Two action buttons (per user decision):**
   - **"Record Payment"** (primary button, amber/primary color): Inserts a settlement row into Supabase:
     - If direction is "you_owe": paid_by = current user, paid_to = other userId
     - If direction is "owed_to_you": paid_by = other userId, paid_to = current user
     - amount = entered amount, household_id = current household, created_by = current user
     - On success: show brief success state, then router.back()
   - **"Request via Venmo"** (secondary button, Venmo blue #3D95CE or similar): Only shown if the other person's profile has a non-null venmo_username.
     - Calls `Linking.openURL` with HTTPS Venmo URL: `https://venmo.com/${username}?txn=charge&amount=${amount.toFixed(2)}&note=${encodeURIComponent(note)}`
     - Note format: "RoomY: Settlement for [household name]"
     - After returning from Venmo, show a "Mark as Settled" button that records the payment (same insert as Record Payment above). Per user decision: after returning from Venmo, user manually taps "Mark as settled".
     - If no venmo_username: show hint text "[Name] hasn't added their Venmo username yet"

**Error handling:** Show error below buttons on failure. Disable buttons + ActivityIndicator during submission.

**Add Stack.Screen route** for `expenses/settle` in `app/(app)/_layout.tsx` with headerShown: true, title "Settle Up", same header styling as other screens.
