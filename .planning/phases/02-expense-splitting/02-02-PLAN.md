**Create `app/(app)/expenses/add.tsx`:**

A full-screen form (not modal) pushed via expo-router. Follow existing NativeWind styling patterns.

**Form fields:**
1. **Description** — TextInput, required. Below the input, show a horizontal ScrollView of recent description suggestions. Query last 10 distinct descriptions from expenses table for this household (SELECT DISTINCT description FROM expenses WHERE household_id = ? ORDER BY created_at DESC LIMIT 10). Tapping a suggestion fills the description field.

2. **Amount** — TextInput with keyboardType="decimal-pad", prefixed with "$". Required, must be > 0. Format: allow digits and one decimal point, max 2 decimal places.

3. **Payer** — Horizontal list of household members (profile avatar initials + name). Current user selected by default. Single selection (radio-style). Fetch members using the two-query pattern from Phase 1 (household_members + profiles separately, combine client-side).

4. **Split between** — Vertical list of household members with checkboxes. ALL selected by default. User can tap to deselect individuals. At least 1 member must remain selected. Show computed share amount next to each checked member (total / selectedCount, formatted with Intl.NumberFormat currency).

**Penny rounding:** Use the distribute-remainder algorithm from RESEARCH.md Pattern 5:
- baseShare = Math.floor(amount * 100 / memberCount) / 100
- remainder = Math.round((amount - baseShare * memberCount) * 100)
- First N members get baseShare + 0.01

**Submit action:**
1. Insert expense row: { household_id, description, amount, paid_by, created_by: current user }. Use `.insert().select().single()` to get the expense ID back.
2. Insert expense_splits rows: one per selected member with computed share_amount.
3. On success, router.back() to expenses tab.

**Error handling:** Show error message below submit button if insert fails. Disable button + show ActivityIndicator during submission.

**Header:** Title "Add Expense", with cancel button (router.back()).

**Add Stack.Screen route** for `expenses/add` in `app/(app)/_layout.tsx` with headerShown: true, title "Add Expense", same header styling as other screens (backgroundColor: "#fefdfb", tintColor: "#f9a825", shadowVisible: false). Also add route for `expenses/[id]`.
