  <action>
Create migration file with:

**Tables:**
1. `expenses` — id (UUID PK), household_id (FK households CASCADE), description (TEXT NOT NULL), amount (NUMERIC(10,2) NOT NULL CHECK > 0), paid_by (FK auth.users NOT NULL), created_by (FK auth.users NOT NULL), created_at (TIMESTAMPTZ DEFAULT now()), updated_at (TIMESTAMPTZ DEFAULT now())
2. `expense_splits` — id (UUID PK), expense_id (FK expenses CASCADE), user_id (FK auth.users NOT NULL), share_amount (NUMERIC(10,2) NOT NULL CHECK > 0), UNIQUE(expense_id, user_id)
3. `settlements` — id (UUID PK), household_id (FK households CASCADE), paid_by (FK auth.users NOT NULL), paid_to (FK auth.users NOT NULL), amount (NUMERIC(10,2) NOT NULL CHECK > 0), created_by (FK auth.users NOT NULL), created_at (TIMESTAMPTZ DEFAULT now())

**Indexes:**
- idx_expenses_household_id ON expenses(household_id)
- idx_expenses_created_at ON expenses(household_id, created_at DESC) — for history ordering
- idx_expense_splits_expense_id ON expense_splits(expense_id)
- idx_expense_splits_user_id ON expense_splits(user_id)
- idx_settlements_household_id ON settlements(household_id)

**Function:**
- `get_household_balances(p_household_id UUID)` — SECURITY DEFINER, STABLE, SET search_path = '', LANGUAGE sql. Returns TABLE(user_id UUID, net_amount NUMERIC). Computes net balances from current user's perspective using CTEs: expense_debts (money owed TO payer BY split members, excluding self-splits), settlement_credits (payments reducing debt), combined (union all from current user's perspective with positive = they owe me, negative = I owe them). GROUP BY other_user, HAVING SUM != 0. Use exact pattern from 02-RESEARCH.md Pattern 2.

**RLS (enable on all 3 tables):**
Follow existing get_user_household_ids() pattern from 00001_foundation.sql. No self-referencing subqueries.

expenses:
- SELECT: `household_id IN (SELECT public.get_user_household_ids())`
- INSERT: `household_id IN (SELECT public.get_user_household_ids()) AND created_by = auth.uid()`
- UPDATE: `household_id IN (SELECT public.get_user_household_ids())` — any member can edit per user decision
- DELETE: `household_id IN (SELECT public.get_user_household_ids())` — any member can delete per user decision

expense_splits:
- SELECT: expense_id belongs to household user is member of — `expense_id IN (SELECT id FROM public.expenses WHERE household_id IN (SELECT public.get_user_household_ids()))`
- INSERT: same check as SELECT — member of the expense's household
- DELETE: same check — for when expenses are edited/deleted (CASCADE handles most, but explicit policy needed)

settlements:
- SELECT: `household_id IN (SELECT public.get_user_household_ids())`
- INSERT: `household_id IN (SELECT public.get_user_household_ids()) AND created_by = auth.uid()`

**Triggers:**
- expenses_updated_at BEFORE UPDATE — reuse existing `public.update_updated_at()` function from 00001_foundation.sql

**Apply migration via Supabase MCP** (`mcp__supabase__apply_migration`).
