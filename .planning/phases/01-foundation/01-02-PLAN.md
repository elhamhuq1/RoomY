3. Create `lib/auth-utils.ts` with three exported functions:

   a. `signInWithGoogle()`:
      - Configure GoogleSignin with `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID`
      - Call `GoogleSignin.hasPlayServices()` then `GoogleSignin.signIn()`
      - Pass `response.data.idToken` to `supabase.auth.signInWithIdToken({ provider: 'google', token })`
      - Return `{ data, error }` -- do NOT use `signInWithOAuth` (browser redirect, per RESEARCH.md anti-pattern)
      - Per RESEARCH.md Pattern 6

   b. `signInWithApple()`:
      - Guard: `if (Platform.OS !== 'ios') return` (Apple Sign-In is iOS only natively per RESEARCH.md Open Question 3)
      - Use `expo-apple-authentication` to get identity token
      - Pass to `supabase.auth.signInWithIdToken({ provider: 'apple', token })`
      - CRITICAL: Capture `credential.fullName` on first sign-in and call `supabase.auth.updateUser({ data: { full_name } })` (Apple only sends name once, per Pitfall 3)
      - Per RESEARCH.md Pattern 7

   c. `requestPasswordReset(email: string)`:
      - Call `supabase.auth.resetPasswordForEmail(email, { redirectTo: 'com.roomy://reset-password' })`
      - Return `{ error }`
      - Per RESEARCH.md Code Example: Password Reset Flow
