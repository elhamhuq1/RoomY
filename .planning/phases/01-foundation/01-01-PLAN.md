   ```
   npx expo install expo-router expo-linking expo-constants expo-status-bar
   npx expo install @supabase/supabase-js react-native-url-polyfill expo-sqlite
   npx expo install nativewind react-native-reanimated@~3 react-native-safe-area-context
   npm install --save-dev tailwindcss@^3.4.17 prettier-plugin-tailwindcss@^0.5.11
   npx expo install @react-native-google-signin/google-signin expo-apple-authentication
   npx expo install expo-sharing @expo/vector-icons
   ```

   - Set ios.bundleIdentifier "com.roomy.app", android.package "com.roomy.app"
   - Set main entry to "expo-router/entry"

4. Configure `babel.config.js`:
   ```javascript
   presets: [
     ["babel-preset-expo", { jsxImportSource: "nativewind" }],
     "nativewind/babel",
   ```

   - Content paths: `./app/**/*.{ts,tsx}`, `./components/**/*.{ts,tsx}`, `./lib/**/*.{ts,tsx}`
   - Preset: `require("nativewind/preset")`
   - Extended borderRadius: xl (16px), 2xl (24px)

7. Create `global.css` with `@tailwind base; @tailwind components; @tailwind utilities;`

8. Create `.env.example` with all required env vars:
   ```
   EXPO_PUBLIC_SUPABASE_URL=your_supabase_url
   EXPO_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID=your_google_web_client_id
   ```
