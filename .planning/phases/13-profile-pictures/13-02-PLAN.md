**Create `components/ui/AvatarUpload.tsx`:**

Props interface:
```typescript
interface AvatarUploadProps {
  userId: string;
  name: string;
  avatarUrl?: string | null;
  size?: 'md' | '2xl';           // small (lists) or large (profile screens)
  showBadgeAlways?: boolean;      // true in onboarding, false (default) in settings
  onUploadComplete: (url: string | null) => void;  // called after upload or remove
  onError: (message: string) => void;               // called on failure
}
```

Implementation:
1. Render a `<Pressable onPress={showActionSheet}>` wrapping `<Avatar userId={userId} name={name} size={size} avatarUrl={avatarUrl} />`
2. Camera badge: positioned absolutely at bottom-right of the avatar.
   - Small circle (size ~24px) with `backgroundColor: '#2D6A4F'` (wintergreen).
   - Contains `<Ionicons name="camera" size={14} color="#fff" />`.
   - Position: `{ position: 'absolute', bottom: 0, right: 0 }`.
   - Visibility logic: if `showBadgeAlways` is true, always show. Otherwise, show only when `!avatarUrl` (no photo set).

3. Action sheet via `Alert.alert('Profile Photo', undefined, buttons)`:
   - When NO photo exists (`!avatarUrl`): buttons = ["Take Photo", "Choose from Library", "Cancel"]
   - When photo EXISTS (`avatarUrl`): buttons = ["Take Photo", "Choose from Library", "Remove Photo" (style: 'destructive'), "Cancel" (style: 'cancel')]

4. `handleCamera` function:
   - Call `pickAndUploadAvatar(userId, 'camera')` from `@/lib/avatar-upload`.
   - Catch errors: if `error.message === 'CAMERA_PERMISSION_DENIED'`, call `onError('Camera access is needed to take a profile photo.')`.
   - For other errors, call `onError('Failed to upload photo. Please try again.')`.
   - On success (non-null return), call `onUploadComplete(url)`.

5. `handleGallery` function:
   - Call `pickAndUploadAvatar(userId, 'gallery')`.
   - On error, call `onError('Failed to upload photo. Please try again.')`.
   - On success, call `onUploadComplete(url)`.

6. `handleRemove` function:
   - Show confirmation dialog: `Alert.alert('Remove profile photo?', 'Your avatar will return to initials.', [{ text: 'Cancel', style: 'cancel' }, { text: 'Remove', style: 'destructive', onPress: async () => { ... } }])`.
   - On confirm: call `removeAvatar(userId)` from `@/lib/avatar-upload`. On success, call `onUploadComplete(null)`. On error, call `onError('Failed to remove photo. Please try again.')`.

Import `Alert, Pressable, View` from react-native, `Ionicons` from `@expo/vector-icons`, `Avatar` from `./Avatar`, `pickAndUploadAvatar, removeAvatar` from `@/lib/avatar-upload`.
