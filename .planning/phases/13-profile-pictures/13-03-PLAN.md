**Add Supabase Realtime subscription for profiles table changes (locked CONTEXT.md decision: "Household members' avatar updates pushed via Supabase Realtime subscription").**

The home screen (`app/(app)/(tabs)/index.tsx`) already fetches member profiles and passes them to MembersCard and other components. Add a Realtime subscription here so avatar changes from other household members propagate immediately.

**Implementation:** Follow the existing Realtime pattern used in `app/(app)/(tabs)/groceries.tsx`:

1. Inside the existing `useEffect` that sets up data fetching (or in a new `useEffect`), add a Supabase Realtime channel subscription:
   ```typescript
   const channel = supabase
     .channel(`profiles-avatars-${household.id}`)
     .on(
       'postgres_changes',
       {
         event: 'UPDATE',
         schema: 'public',
         table: 'profiles',
       },
       (payload) => {
         const updated = payload.new as { id: string; avatar_url: string | null };
         // Only process if this user is a known household member
         setMembers((prev) =>
           prev.map((m) =>
             m.id === updated.id
               ? { ...m, avatar_url: updated.avatar_url }
               : m
           )
         );
       }
     )
     .subscribe();

   return () => { supabase.removeChannel(channel); };
   ```

2. Since the `profiles` table has no `household_id` column, the subscription receives ALL profile updates. The client-side `setMembers` update naturally filters to only known members (the `.map` only matches IDs already in the `members` array).

3. This ensures that when any household member uploads or removes their avatar, the home screen's MembersCard (and any other component receiving members as props from index.tsx) updates immediately without a manual refresh.

**Note:** Other screens (settings/members, member-welcome) use `useCachedFetch` which refetches on screen focus. The Realtime subscription on the home screen covers the primary viewing context. The focus-refetch on secondary screens provides adequate freshness for the rare event of avatar changes.
