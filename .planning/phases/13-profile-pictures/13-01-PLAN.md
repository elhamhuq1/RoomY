2. Create the Supabase Storage `avatars` bucket and RLS policies. Run the following SQL via the Supabase MCP `apply_migration` tool (migration name: `create_avatars_bucket`):

```sql
-- Create the avatars bucket (public reads, RLS for writes)
INSERT INTO storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
VALUES ('avatars', 'avatars', true, 5242880, ARRAY['image/jpeg', 'image/png', 'image/webp']);

-- SELECT: Anyone can view avatars (public bucket)
CREATE POLICY "Avatar images are publicly accessible"
ON storage.objects FOR SELECT
USING (bucket_id = 'avatars');

-- INSERT: Authenticated users can upload to their own folder
CREATE POLICY "Users can upload their own avatar"
ON storage.objects FOR INSERT
TO authenticated
WITH CHECK (
  bucket_id = 'avatars'
  AND (storage.foldername(name))[1] = auth.uid()::text
);

-- UPDATE: Users can overwrite their own avatar (needed for upsert)
CREATE POLICY "Users can update their own avatar"
ON storage.objects FOR UPDATE
TO authenticated
USING (
  bucket_id = 'avatars'
  AND (storage.foldername(name))[1] = auth.uid()::text
);

-- DELETE: Users can delete their own avatar
CREATE POLICY "Users can delete their own avatar"
ON storage.objects FOR DELETE
TO authenticated
USING (
  bucket_id = 'avatars'
  AND (storage.foldername(name))[1] = auth.uid()::text
);
```

3. Also update the local migration file `supabase/migrations/00001_foundation.sql` by appending the same SQL at the bottom (preserving existing content).

**Create `lib/avatar-upload.ts`:**

Create a utility module with two exported functions:

1. `pickAndUploadAvatar(userId: string, source: 'camera' | 'gallery'): Promise<string | null>`
   - If source is 'camera', call `ImagePicker.requestCameraPermissionsAsync()` first. If not granted, throw `new Error('CAMERA_PERMISSION_DENIED')`.
   - Call the appropriate launcher (`launchCameraAsync` for camera, `launchImageLibraryAsync` for gallery) with options:
     - `mediaTypes: ['images']`
     - `allowsEditing: true` (enables native square crop)
     - `aspect: [1, 1]` (enforced on Android; iOS always crops square)
     - `quality: 0.8` (silent compression per user decision)
   - If `result.canceled`, return `null`.
   - **Resize to max 512x512 (locked CONTEXT.md decision):** If `image.width > 512 || image.height > 512`, use `expo-image-manipulator` to resize:
     ```typescript
     import { manipulateAsync, SaveFormat } from 'expo-image-manipulator';
     // ...
     let finalUri = image.uri;
     if (image.width > 512 || image.height > 512) {
       const manipulated = await manipulateAsync(
         image.uri,
         [{ resize: { width: 512, height: 512 } }],
         { compress: 0.8, format: SaveFormat.JPEG }
       );
       finalUri = manipulated.uri;
     }
     ```
     Since the image is already square-cropped (1:1 aspect), resizing to 512x512 maintains the aspect ratio. Use `finalUri` for all subsequent steps instead of `image.uri`.
   - Convert to ArrayBuffer: `const arraybuffer = await fetch(finalUri).then(res => res.arrayBuffer())`
   - Determine file extension: use 'jpeg' when resized (manipulator outputs JPEG), otherwise extract from URI, default to 'jpeg'.
   - Upload to Supabase Storage: `supabase.storage.from('avatars').upload(\`${userId}/avatar.${fileExt}\`, arraybuffer, { contentType: image.mimeType ?? 'image/jpeg', upsert: true })`
   - On upload error, throw the error.
   - Get public URL: `supabase.storage.from('avatars').getPublicUrl(filePath)`
   - Append cache buster: `\`${data.publicUrl}?t=${Date.now()}\``
   - Update profiles table: `supabase.from('profiles').update({ avatar_url: avatarUrl }).eq('id', userId)`
   - Return the avatarUrl string.

2. `removeAvatar(userId: string): Promise<void>`
   - List files in user's folder: `supabase.storage.from('avatars').list(userId)`
   - If files exist, remove them: `supabase.storage.from('avatars').remove(filePaths)`
   - Clear avatar_url in profile: `supabase.from('profiles').update({ avatar_url: null }).eq('id', userId)`

Import `supabase` from `@/lib/supabase`, `* as ImagePicker` from `expo-image-picker`, and `{ manipulateAsync, SaveFormat }` from `expo-image-manipulator`.
